  解析代码

  已用实际文件验证过，输出 {'mon': {'high': '06:12', 'low': '12:30'}, 'tue': {'high': '06:58', 'low': '13:15'}}：

  def parse_tide_table(md: str) -> dict[str, dict[str, str]]:
      rows = [
          [cell.strip() for cell in line.strip().strip("|").split("|")]
          for line in md.splitlines()
          if line.strip().startswith("|")
      ]
      table = [row for row in rows if not all(set(cell) <= {"-"} for cell in row)]
      header, *data = table
      return {row[0]: dict(zip(header[1:], row[1:])) for row in data}

  逻辑：取所有以 | 开头的行拆成单元格，过滤掉 |---|---| 分隔行，首行作表头，其余行按 day 作外层键、high/low 作内层键。
